# 🧸 Cocok-Cocokan

Permainan mencocokkan gambar untuk anak usia **3 tahun ke atas**, dalam Bahasa Indonesia.

Si kecil melihat satu gambar besar, lalu mengetuk pasangannya. Setiap jawaban benar disambut suara, ucapan pujian, dan bintang. Kumpulkan 5 bintang untuk perayaan kecil! 🏆

**▶️ Main sekarang:** [https://USERNAME.github.io/cocok-cocokan/](https://USERNAME.github.io/cocok-cocokan/)

Gratis, tanpa iklan, tanpa perlu install. Bisa dimainkan di HP, tablet, maupun laptop.

---

## 🎨 Tema permainan

| Tema | Yang dicocokkan | Contoh |
|---|---|---|
| 🐰 Hewan | Hewan dan makanannya | Kelinci → wortel |
| 🍎 Buah & Sayur | Gambar yang sama | Apel → apel |
| 🔺 Warna & Bentuk | Bentuk dan warna yang sama | Lingkaran merah → lingkaran merah |
| 🧦 Benda | Benda sehari-hari yang berpasangan | Kaus kaki → sepatu |
| 👤 Bayangan | Gambar dan bayangannya | Gajah → siluet gajah |
| 🚗 Kendaraan | Kendaraan dan tempatnya | Kapal → laut |
| 🖐️ Berapa Banyak? | Jumlah benda yang sama (1–5) | 3 apel → 3 titik |
| 😊 Perasaan | Wajah dengan perasaan yang sama | Senang → senang |

## ✨ Fitur

- **Suara dan ucapan** dalam Bahasa Indonesia, misalnya *"Kelinci suka makan wortel!"*
- **Ketuk gambar besar** untuk mendengar namanya, untuk melatih kosakata
- **Dua tingkat kesulitan**: 2 pilihan (mudah) atau 3 pilihan
- **Salah tidak apa-apa**: anak cukup mencoba lagi, tanpa hukuman atau skor berkurang
- **Mode gelap** otomatis mengikuti pengaturan perangkat
- Bisa mematikan suara kapan saja

## 👨‍👩‍👧 Tips untuk orang tua

1. **Mainkan bersama.** Untuk usia 3 tahun, permainan ini paling bermanfaat bila didampingi.
2. **Mulai dari 2 pilihan.** Naikkan ke 3 pilihan setelah si kecil lancar.
3. **Sebut namanya bersama-sama.** Tunjuk gambarnya, ucapkan namanya, lalu biarkan anak mencari pasangannya sendiri.
4. **Ajak bercerita.** Misalnya: *"Kucing suka ikan. Kalau kamu suka makan apa?"*
5. **Batasi waktu layar.** Sesi singkat 5–10 menit sudah cukup.

## 📱 Catatan

- Gambar memakai emoji, jadi tampilannya sedikit berbeda di iPhone, Android, dan laptop.
- Ucapan memakai suara bawaan perangkat. Jika perangkat tidak memiliki suara Bahasa Indonesia, ucapan bisa terdengar kurang tepat atau tidak muncul. Efek bunyi tetap berjalan.
- Pastikan HP tidak dalam mode senyap agar suara terdengar.

## 🛠️ Teknis

Seluruh permainan ada dalam satu file `index.html` (HTML, CSS, dan JavaScript biasa). Tidak ada data yang dikumpulkan dan tidak memerlukan server.

Untuk menjalankan sendiri, unduh `index.html` lalu buka di browser.
